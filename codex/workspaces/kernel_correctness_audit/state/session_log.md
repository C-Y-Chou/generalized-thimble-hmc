## 2026-05-07 JST Before Probe 3
- Probe 3 target: local phase-space volume preservation for the successful proposal map.
- Design:
  - Added standalone diagnostic app `src/apps/probe_hmc_volume.f90`.
  - The app calls the same `rattle_step_core` used in production and propagates a user-specified tangent momentum.
  - It currently targets the 1D toy model with local coordinates `(q, c)`, where `q=x(2)` and tangent momentum is represented as `p = J(q)c`.
- Diagnostic quantity:
  - raw determinant: `log|det d(q',c')/d(q,c)|`.
  - metric-corrected determinant: `log|det| + 2log|J(q')| - 2log|J(q)|`.
  - The metric-corrected value is the primary volume-preservation check because `(q,c)` is not a unit Euclidean phase-space coordinate chart.
- Planned run:
  - withfb, p28, RG enabled, `cttol=1e-13`, `QN tol=1e-13`, post-refine enabled.
  - flow time `0.35`, `L=2`, `nstep=20`.
  - finite-difference eps values: `1e-4`, `3e-5`, `1e-5`.
  - 16 successful base points per eps, up to 600 candidate points.
- Pass criterion:
  - at least 4 branch-stable finite-difference rows per eps.
  - max absolute metric-corrected log-volume <= `1e-4`.
- Conditions not checked in this probe:
  - global branch-measure symmetry.
  - volume at branch boundaries / RG-reject discontinuity surfaces.
